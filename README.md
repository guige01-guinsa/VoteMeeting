제가 Codex에게 추가로 전달하고 싶은 지시사항

이 프로젝트는 학습용 예제가 아니라 실제 업무용 프로그램입니다.

따라서 Codex는 다음 원칙을 반드시 지켜야 합니다.

항상 동작하는 코드만 작성한다.
기능 추가 시 기존 기능을 깨뜨리지 않는다.
하나의 Commit마다 실행 가능한 상태를 유지한다.
오류 처리와 예외 처리를 우선한다.
UI보다 정확한 OCR 판독과 안정적인 자동 집계를 우선한다.
코드에는 충분한 주석을 작성한다.
구조는 확장 가능하게 설계하되, 초기 구현은 최대한 단순하게 유지한다.
